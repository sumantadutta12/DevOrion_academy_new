About DevOps & Cloud

DevOps and cloud practices connect source code with the environments where applications run. Explore version control, containers, delivery pipelines, configuration, cloud deployment, and operational visibility.

  • Understand how source changes move through a delivery pipeline.
  • Package an application and manage its configuration.
  • Explore monitoring, troubleshooting, and recovery workflows.
